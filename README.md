# Contacts API 

API REST simples desenvolvida em **Spring Boot** para o gerenciamento de contatos, como parte da atividade da **Aula 03**.

O objetivo deste projeto é colocar a API em funcionamento a partir do zero, realizando a configuração, implementação dos endpoints CRUD básicos, integração com banco de dados em memória (H2) e documentação dos testes realizados.

---

## Tecnologias Utilizadas

- **Java** (17 ou superior)
- **Spring Boot** (Spring Web, Spring Data JPA)
- **H2 Database** (Banco de dados em memória)
- **Maven** (Gerenciador de dependências)
